# Streamlit Utility Tool 🛠️

This is a simple yet functional utility app built with [Streamlit](https://streamlit.io/), developed as part of a Software Configuration Management (SWE 442) course project. The goal of this project is to demonstrate the use of Git and GitHub for version control, branching, merging, tagging, and documenting a software release process.

---

## 🚀 Features

### 📟 Calculator
- Perform basic arithmetic operations: Add, Subtract, Multiply, Divide
- Enhanced UI with result shown in a colored box

### 📝 To-Do List
- Add, edit, and delete tasks
- Mark tasks as completed
- Task priorities (Low, Medium, High)
- Automatic timestamp when task is added
- Clear all completed tasks
